Caromino 戦闘VFX 参考画像比較と改善結果
作成日: 2026年11月2日

1. 対象と前提

- 対象は DirectX11 / C++ 製 Caromino の戦闘Presentation層。
- 参考画像の特徴を、既存の CollisionImpactEvent、CollisionPresentationRules、
  GamePresentation、CollisionVfxSystem、PlayerBall軌跡へ統合した。
- 攻撃力、HP、質量、反発、摩擦、移動、衝突判定、ダメージ順、敵AI、
  重量スタック経済は変更していない。
- 因果関係を誤認させる架空の接続線は追加せず、実際の衝突位置・衝突軸だけを使う。

2. 参考画像と従来画面の比較

従来画面で確認した課題

- CHAIN 10 が単純な文字列で、戦闘の節目としての格が弱かった。
- オレンジ色の軌跡が点列に見え、高速移動方向と速度感が読み取りにくかった。
- 複数の水色リングとダメージ文字が同じ場所へ集中し、衝突中心が埋もれた。
- 撃破表示と通常ダメージが同じ優先度で並び、結果を追いにくかった。
- デバッグ窓表示時、中央上部の利用可能領域が狭く、CHAIN表示がHUDと競合した。

参考画像から採用した要素

- 白熱した中心核、放射状の光条、短寿命の衝撃波という三層構成。
- 重量連鎖の二次衝突は水色、直接衝突と高CHAIN節目は金～橙色で役割を分離。
- 高速球は橙色の外光、赤橙の中間層、明るい金色の芯を持つ軌跡。
- CHAIN 3 / 6 / 10 / 15 を段階化し、高段階は暗い台座、金色枠、光条、
  サイドマーカー、補足文を持つバナーとして表示。
- ダメージ表示は位置候補を探索し、撃破を先に配置する。

3. 実装内容

3.1 衝突中心

- CollisionVfxSystem に固定容量8個の ImpactBurst を追加。
- 強衝突・中衝突・CHAIN節目で、中心の多層円、白い核、放射光条を生成する。
- 敵同士の二次衝突では衝突軸の両方向へ対称な水色シェブロンを出す。
  対称表示のため、記録されていない伝播元を捏造しない。
- 弱～中の近接リングは、同種・近距離・隣接フレームでも統合し、
  同じ場所へ円が増え続ける状態を抑えた。
- 二次衝突は原則水色を保ち、最上位節目だけピーク色へ移行する。

3.2 PlayerBall高速軌跡

- TrailPoint に表示専用 intensity を保持し、現在速度から0.28～1.0へ正規化。
- 高速時ほど記録間隔を短くし、履歴上限は144点。
- GamePresentation 側で直近112点を画面投影し、外光・中間・芯の3層線を描画。
- 既存の残像球は速度に応じてスケールとフェードを変更した。
- 軌跡値は描画専用で、PlayerBallの速度・位置更新へ書き戻さない。

3.3 CHAIN表示

- 3 / 6 / 10 / 15 の既存閾値を利用し、別カウンタは作っていない。
- 節目表示の寿命を保持し、次の衝突でカウントが進んでも特別表示が即消えない。
- CHAIN 10以上は金～橙色の大型バナー、下線、光条、補足文を表示。
- デバッグ窓表示時は左HUDと右デバッグ窓の間へ寄せ、最終画面では両方と非重複。

3.4 ダメージ・撃破表示

- 撃破ラベルを通常ダメージより先に配置し、暗い角丸背景を追加。
- 16個の決定的な配置候補から、CHAINバナーと既配置ラベルを避ける位置を選ぶ。
- 通常ダメージは同一対象・近接位置・3Presentationフレーム以内だけ表示値を合算。
  ゲームのダメージイベント数、順序、HP計算は変更しない。
- 四方向の黒縁を追加し、緑の盤面や発光上でも文字を読みやすくした。

4. 上限と負荷制御

既存上限を維持

- 火花: 装飾量0 / 1 / 2 / 3 = 0 / 32 / 64 / 96。
- 1フレーム火花生成: 0 / 16 / 32 / 48。
- 衝撃波: 0 / 4 / 8 / 12。
- 新規ImpactBurst: 固定配列8、実運用上限は装飾量から算出し最大6。

現行固定ショット完走時の診断

- impact_events: 18
- sparks_generated / skipped / maximum_active: 71 / 75 / 64
- waves_generated / merged / skipped / maximum_active: 13 / 1 / 4 / 8
- bursts_generated / skipped / maximum_active: 8 / 6 / 4
- maximum_primitive_submissions: 227
- 終了時 active_sparks / waves / bursts: 0 / 0 / 0

参考

- 改善前の同ショットは maximum_primitive_submissions 146。
- 中心核・光条・シェブロン追加後は227で、ImGuiプリミティブ投入が81増加した。
- これは AddLine / AddCircle / AddConvexPoly 等の投入数であり、GPU draw call数ではない。
- 粒子・波・バーストは固定配列を再利用し、毎フレームのVFX用ヒープ確保は追加していない。

7. 実画面確認

改善後保存画像

- captures/CHAIN10_collision_vfx_final2_20261102.png
- captures/CHAIN10_collision_vfx_final2_20261102.json

撮影時

- CHAIN 10
- active_sparks 64
- active_waves 8
- active_bursts 4
- maximum_active_sparks / waves / bursts = 64 / 8 / 4

目視結果

- CHAINバナーは左HUDと右デバッグ窓に重ならない。
- 衝突中心の白い核と金色放射光が、リングの中心を特定できる強さになった。
- 高速球の橙色軌跡は、従来の点列より連続方向を追いやすい。
- 撃破ラベルは通常ダメージより前面かつ背景付きで判別できる。
- 通常ダメージの密集は軽減したが、同時発生数が配置候補を超える極端な場面では
  完全な非重複を保証しない。情報を消すより、近接合算と優先配置を選択した。
