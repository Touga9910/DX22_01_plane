# Caromino 敵被弾リアクション・撃破VFX 実装検証

作成日：2026年11月2日
対象：DirectX11 / C++版 Caromino（Debug x64）

結論
----
有効ダメージに連動する敵球本体のヒットフラッシュ、撃破時だけ発生する白金色バースト、1ショット内のユニーク撃破数に基づく複数撃破表示を実装した。
重量軸固定ショットでは演出OFF/ONとも、有効敵同士衝突11、撃破3、物理ステップ149、敵総移動距離585.5615844726562で完全一致した。HP0の敵を即時削除せず、ショット終了まで従来どおり物理連鎖へ参加する仕様も維持している。


A. 実装概要
============

1. 被弾フラッシュ
----------------
- 既存のCombatFeedback（実際に適用されたダメージと撃破確定の通知）に対象敵の識別情報を最小限追加し、物理衝突だけでは発火しないようにした。
- GamePresentationが固定長16枠のHitReactionを管理し、EnemyBallの一時フラッシュ係数だけを更新する。毎フレームの動的メモリ確保はない。
- EnemyBallでは既存のベース色／衝突段階色を先に算出し、その上へ白～淡い黄色を合成する。特殊状態色を単純上書きしない。
- 同じ敵への連続被弾は残り時間と強度を更新する。別の敵は独立して点滅する。
- ダメージ0はフラッシュ対象外。位置、速度、質量、半径、Collider、Transformスケールは変更しない。

2. 撃破専用VFX
---------------
- CollisionVfxSystemのImpactBurst、衝撃波、火花、寿命管理、優先度、表示上限を再利用した。
- 撃破要求は白金色、通常より大きい二重リング、長い光条、短い金色火花として優先度4で投入する。
- 1ショット内で敵ポインタを固定長32枠へ記録し、同じ敵の撃破VFXと撃破数を一度だけ処理する。
- 撃破と通常CollisionImpactが同じ接触に由来する場合、撃破専用VFXを優先して通常側の重複生成を省く。
- CHAIN節目と重なっても、撃破表示を局所優先し、通常衝突＋撃破の二重バーストを避ける。

3. 複数撃破演出
---------------
- CHAINとは別に、1ショット内で新規撃破した敵のユニーク数を保持する。
- 2体撃破で「DOUBLE BREAK」、3体以上で「MULTI BREAK ×N」を短時間表示する。
- 3体以上では撃破ラベルを「連続撃破！」へ強調する。
- ショット開始時、戦闘開始時、戦闘終了／停止時に状態をリセットする。

4. 既存衝突VFXとの連動
----------------------
- 衝突VFXの既存上限（火花、衝撃波、ImpactBurst、1フレーム生成予算）を変更していない。
- 撃破要求も既存プールと選別規則を通るため、上限超過時は通常効果より優先されるが無制限には増えない。
- 敵被弾フラッシュ、撃破専用VFX、複数撃破表示は個別に無効化できる。


B. コード変更
============

主な変更・追加ファイル
----------------------
- DX22_01_plane/CombatPresentationRules.h（追加）
  ダメージ別フラッシュ時間・強度、複数撃破段階、固定長上限を純粋ルールとして定義。
- DX22_01_plane/GameEvent.h
  EnemyDamageEvent / PocketFeedbackEventへtargetKeyとtargetEnemyIdを追加。
- DX22_01_plane/GameBattleEvents.h、Game.cpp、Game.h
  既存CombatFeedback / PocketFeedbackの経路で対象敵を通知し、診断値を公開。
- DX22_01_plane/BallCollisionComponent.cpp、GameProgression.cpp、EnemyBall.cpp
  プレイヤー対敵、敵対敵、連鎖衝撃、アンカー範囲攻撃、ボスBreakBallの実ダメージ経路から既存フィードバックを発行。
- DX22_01_plane/EnemyBall.h / EnemyBall.cpp
  ベースTint・衝突段階Tint・一時被弾フラッシュを合成。
- DX22_01_plane/GamePresentation.h / GamePresentation.cpp
  固定長HitReaction、ユニーク撃破追跡、複数撃破表示、状態クリア、診断値を実装。
- DX22_01_plane/CollisionVfxSystem.h / CollisionVfxSystem.cpp
  撃破専用の色・二重リング・光条・火花・診断値を既存予算内へ追加。
- DX22_01_plane/SettingsManager.h / SettingsManager.cpp
  3個の独立設定をロード／セーブ。
- DX22_01_plane/GameSettingsRuntime.h / GameSettingsRuntime.cpp
  Presentation向け設定アクセサを追加。
- DX22_01_plane/GameMcpBridge.cpp
  被弾、撃破、重複抑制、同時数、省略数、プリミティブ数の診断値を公開。
- DX22_01_plane/tools/test_shot_physics_telemetry.cpp
  ダメージ段階、ダメージ0抑制、複数撃破段階の純粋ルールテストを追加。
- DX22_01_plane/DX22_01_plane.vcxproj / .filters
  CombatPresentationRules.hをプロジェクトへ登録。

利用したイベントと責務分離
--------------------------
Physics / Rules
  -> GameBattleEvents::CombatFeedback（適用ダメージ・撃破・対象敵）
  -> EnemyDamageEvent / PocketFeedbackEvent
  -> GamePresentation
  -> EnemyBall::SetPresentationHitFlash / CollisionVfxSystem

ゲームルール側から描画処理を直接呼んでいない。Presentation通知は既に確定した結果を表示するだけで、ダメージ計算や撃破判定を再実行しない。

対応経路
--------
- プレイヤー球対敵、敵対敵の実ダメージ
- 連鎖衝撃
- アンカーのフィニッシャー／範囲ダメージ
- ボスBreakBall経路
- ポケット撃破

注意：ポケットへ入った対象は表示キューへ移るため、球本体フラッシュを視認できる時間は短い。撃破専用VFXはポケット入口位置で発生する。


C. 演出設定
============

被弾フラッシュ初期値
--------------------
- ダメージ1：0.08秒、白色寄り、強度0.52
- ダメージ2～3：0.12秒、強い白色、強度0.72
- ダメージ4以上：0.16秒、白～淡黄色、強度0.92
- 撃破確定：0.18秒、強度1.00へ更新
- フェード：残り時間比の二乗で自然減衰

撃破VFX初期値
-------------
- 色：0xffbdeaff（白金／淡い金色）
- 衝撃波：二重リング、開始半径1.1、終了半径12.5、太さ4.0、寿命0.46秒
- 中心光：寿命0.42秒、コア半径28、光条長96、14本
- 火花：速度46、寿命0.38秒、サイズ3.8、通常より3個多い要求（既存上限14個でクランプ）
- 優先度：4

複数撃破
--------
- 1体：通常の撃破VFXのみ
- 2体：DOUBLE BREAK、1.05秒
- 3体以上：MULTI BREAK ×N、1.30秒

ON/OFF
------
ポーズ／設定画面へ以下を追加した。保存キーも独立している。
- 敵の被弾フラッシュ：enemy_hit_flash_enabled
- 撃破専用VFX：defeat_vfx_enabled
- 複数撃破表示：multi_defeat_effects_enabled

F. 実画面確認
============

保存したスクリーンショット
--------------------------
- captures/enemy_defeat_multi_vfx_clean_20261102.png
- 診断メタデータ：captures/enemy_defeat_multi_vfx_clean_20261102.json
- ショット完了値：captures/enemy_defeat_multi_vfx_clean_20261102_final.json

確認結果
--------
- 通常被弾：敵球が短い白色フラッシュになり、元の色へ復帰。
- 強被弾：ダメージ段階に応じて時間と黄色成分が増加。
- 単体撃破：白金の中心光、二重リング、光条、撃破ラベルを確認。
- 複数撃破：MULTI BREAK ×3と「連続撃破！」を確認。
- CHAIN 10以上：CHAIN 10、3体撃破、白金バースト、ダメージ数字が同一フレームで表示され、ガイドUIを閉じた状態で撮影。
- 撃破済み敵：ショット中も移動・再衝突し、11衝突／149ステップの連鎖結果を維持。


G. 残課題
==========

- 戦闘SE（今回の変更禁止範囲）
- 敵HP表示の視認性改善
- 特殊能力ごとの専用演出
- 貫通・反射・アンカーの固有VFX
- GPUフレーム時間／CPUフレーム時間の継続計測
- ポケット直前の球本体フラッシュをより長く見せる場合は、物理対象とは分離した残像表示の設計が必要


最終判定
========

演出はHP減少・撃破確定の事実だけを参照し、物理・ダメージ・撃破条件・敵削除タイミングを変更していない。固定ショットの物理結果はOFF/ONで一致し、CHAIN 10かつ3体撃破の実画面でも、被弾・撃破・複数撃破を文字だけに依存せず判別できる状態になった。
